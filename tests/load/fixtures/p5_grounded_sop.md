# P5 合成設備復歸與換線 SOP

文件識別碼：`P5-SOP-RESET-042`

本文件只供隔離 staging 容量驗證，不含任何客戶或真實工廠資料。

## 設備復歸

1. 先按下停止鍵，確認主軸與輸送帶完全停止。
2. 確認壓力表歸零，壓力必須落在 0–0.05 MPa。
3. 檢查安全門內無人員、工具或殘料後，才可解除安全門鎖。
4. 清除警報並以低速點動；確認無異音、無漏氣且感測器均回到正常狀態。
5. 由班長確認後恢復自動模式。壓力未歸零、安全門感測異常或仍有異音時，禁止復歸並通知維修。

## 換線前確認

換線前必須完成停機掛牌、清除前批物料、核對新工單與治具編號，並由第二人複核首件參數。若治具編號不符或安全連鎖未通過，不得啟動。

## 盤點差異處理

發現帳實不符時先隔離該儲位，保留原標籤與掃碼紀錄，完成第二人複盤後才可建立差異單。不得直接修改帳面數量掩蓋差異。
