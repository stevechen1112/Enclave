# A3 語音／文字測試腳本：客戶詢價（約 30 秒）

**用途**：劇本 A 任務 A3「任務工作區開報價單」（`/job/tasks/quote`）。
**優先**：Demo／測試時**先用下方「文字備案句」**（穩定可重現）；語音為加分項。
**錄音指引**：安靜環境一版即可；語速自然。中英夾雜的料號是辨識觀察重點。

---

## 文字備案句（Demo 首選，貼上即可）

```
幫翔展科技報價，料號 P-200，三百個，單價一千一百五十
```

預期立即抽出：`customer=翔展科技`、`part_number=P-200`、`quantity=300`、`unit_price=1150`。

---

## 語音唸稿

> 「欸，翔展科技剛才來電話，他們那個美國案子要正式下單了。要 P-200，三百 pcs，對，三百台。他們問說什麼時候可以交貨，還有價格是不是跟上個月一樣。你幫我開一張報價單，付款條件照舊，月結三十天。喔對了，他們說這批是要走外銷的，規格要照之前那個要求書，你順便確認一下版本對不對。」

## 預期系統行為（評分對照）

| 欄位 | 預期抽取值 | 備註 |
|------|------------|------|
| customer | 翔展科技 | 文字備案句／語音皆應抽出 |
| part_number | P-200 | 中英夾雜料號，語音辨識觀察重點 |
| quantity | 300 | 「三百 pcs／三百個」→ 300 |
| unit_price | 1150 | 文字備案句直接抽出；語音路徑可能需手動確認 |
| payment_terms | （通常需手動） | regex 抽取器目前不覆蓋付款條件；欄位卡手動補「月結30天」 |
| valid_until | （通常需手動） | 可依 D04 報價日 +30 天手動填 |
| 交期回覆 | 14 個工作天 | 問答路徑依 D04 第 3 節（非欄位抽取） |
| 版本判斷 | 應報 v2.1 | 外銷要求書（D06）只有 v2.1 符合（問答路徑） |

## 干擾點（刻意設計）

- 「價格是不是跟上個月一樣」→ 上個月（D05b）是 150 pcs @1,280，本次 300 pcs 應為 1,150，**不應**直接沿用 1,280。
- 「規格要照之前那個要求書」→ 需連結 D06 判斷版本（走問答，不是 parse-text）。
- 使用者若繞去 `/forms/quote` 自己填 → 記為 UX 卡點（主路徑應是任務工作區）。
