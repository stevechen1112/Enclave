## 1. 產品概述

P-200 為捲繞、印刷、貼合製程設計之精密張力控制器，透過張力感知器回授進行閉迴路控制，適用於薄膜、紙張、金屬箔等材料之恆張力捲取與放捲。v2.1 針對戶外與嚴苛環境應用強化防護與通訊能力。

**v2.1 與 v2.0 的規格差異重點**：① 防護等級由 IP54 提升至 IP65；② 工作溫度由 -10–60 °C 擴展為 -20–70 °C；③ 通訊介面新增 CAN bus（CANopen）；外殼改鋁合金壓鑄，重量由 1.8 kg 降為 1.6 kg。詳見第 5 節修訂履歷。

## 2. 主要規格

| 參數 | 規格 |
|------|------|
| 張力控制範圍 | 5–50 N |
| 張力控制精度 | ±1.0% F.S. |
| 控制迴路更新率 | 200 Hz |
| 輸入電源 | 24 VDC ±10% |
| 消耗功率 | 15 W |
| 工作溫度 | -20–70 °C |
| 儲存溫度 | -20–70 °C |
| 防護等級 | IP65（控制盒本體，防塵防水） |
| 通訊介面 | RS-485（Modbus RTU）＋ CAN bus（CANopen） |
| 張力感知器輸入 | 應變規式，0–10 V |
| 輸出 | 磁粉離合器驅動 0–24 V / 3 A |
| 外觀尺寸 | 160 × 120 × 60 mm |
| 重量 | 1.6 kg |

## 3. 功能

- 捲徑自動追蹤與錐度張力控制
- 斷料偵測與停機輸出
- 張力異常趨勢記錄（最近 100 筆）
- CAN bus 連線：可整合 PLC 與遠端監控系統
- 參數設定：面板按鍵、RS-485 或 CAN bus 通訊
