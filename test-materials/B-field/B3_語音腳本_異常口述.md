# B3 語音測試腳本：現場異常口述（約 60 秒）

**用途**：劇本 B 任務 B3「語音異常回報」。
**錄音指引**：**兩版**——① 安靜環境版；② 噪音版（播放廠房白噪音或站在運轉設備 2 公尺外錄製）。語速自然、帶現場口吻，不必文謅謅。

---

## 腳本（唸稿）

> 「喂，我是早班李阿明。EQ-100 剛才，大概九點二十分的時候，機台突然有一陣很尖的異音，然後就跳 E-03 停下來了。我有按 SOP 先停機，沒有再去動它。主軸那邊摸起來……喔不是，我沒有摸，那個很燙不能摸。看起來風扇有在轉，但是之前才修過軸承那邊，我怕又是同樣的問題。現場先停了，材料還掛在上面，等設備課來看。照片我等一下補拍上傳。」

## 預期系統行為（評分對照）

| 欄位 | 預期抽取值 | 備註 |
|------|------------|------|
| equipment_id | EQ-100 | 場景掃碼應已預填，語音為佐證 |
| occurred_at | 當日 09:20 | 「九點二十分」 |
| category | 設備故障 | 由 E-03 推斷 |
| severity | 嚴重（已停機） | 「現場先停了」 |
| description | 異音→E-03 停機、風扇有轉、上月曾修軸承 | 語音轉寫入描述 |
| reporter | 李阿明 | 「我是早班李阿明」 |
| immediate_action | 依 SOP 停機、未觸碰高溫部位 | 「有按 SOP 先停機」 |

## 干擾點（刻意設計）

- 口述中自我修正（「摸起來……喔不是，我沒有摸」）→ 觀察系統是否正確擷取修正後資訊。
- 安全亮點：「那個很燙不能摸」符合 D07b 第 3.3 節——可作為 DEMO 加分點。
- 「之前才修過軸承」→ 對應 D03a 維修紀錄，可追問系統「這台最近修過什麼」驗證場景限定檢索。（用詞刻意不寫死月份，避免與實際測試日期產生矛盾）

## 噪音版評分調整

噪音版辨識率下降屬預期；觀察重點改為：**系統是否明確提示辨識信心不足、關鍵欄位是否標「需確認」、重試流程是否順暢**（對應 UIUX U1／U4）。
