# ADR-017：來源權威、衝突與 know-how 生命週期

- 狀態：Accepted
- 日期：2026-08-25

## 決策

權威依問題情境、適用廠區／客戶／設備、有效期及風險判定，不採單一固定排名。衝突來源並列其版本與適用範圍，不無痕融合。

長訪談逐字稿為 provisional。Know-how 只有具 reviewer、reviewed_at、已生效、未到期且未逾複查日的 approved 卡片可進一般檢索；草稿、退回、過期、未複核一律排除。來源需保留訪談者、音訊／逐字稿位置、整理與核准鏈。

## 後果

安全關鍵問題缺核准、有效期或適用範圍任一條件即 partial／abstain，不自動觸發設備或企業系統寫入。
